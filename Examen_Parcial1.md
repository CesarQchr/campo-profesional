# Desarrollo Web

El desarrollo web es el proceso de crear, construir y mantener sitios web y aplicaciones que funcionan en internet y a los que se accede mediante un navegador

## 1. React

- **Uso principal:** El uso principal de React es la creación de interfaces de usuario eficientes e interactivas para aplicaciones web y móviles en el desarrollo frontend

- **Empresa o vacante real:** Meta (Facebook).

- **Enlace de referencia:** [React Oficial](https://react.dev/)

![React logo](https://upload.wikimedia.org/wikipedia/commons/a/a7/React-icon.svg)

 

## 2. Next.js

 

- **Uso principal:** Crear aplicaciones y sitios web rápidos basados en React que incluyen renderizado en el servidor y optimización automática para motores de búsqueda.
1. Renderizado del lado del servidor
2. Generación estática
3. Desarrollo Full Stack

- **Empresa o vacante real:** Vercel.

- **Enlace de referencia:** [Next.js Oficial](https://nextjs.org/)

![Nextjs logo](https://upload.wikimedia.org/wikipedia/commons/8/8e/Nextjs-logo.svg)

 

## 3. Node.js

 

- **Uso principal:** Ejecutar código JavaScript fuera del navegador web, específicamente en el lado del servidor (backend).
1. Desarrollo de servidores web
2. Gestión de paquetes con NPM
3. Arquitectura de microservicios

- **Empresa o vacante real:** Netflix.

- **Enlace de referencia:** [Node.js Oficial](https://nodejs.org/)

![Node logo](https://upload.wikimedia.org/wikipedia/commons/d/d9/Node.js_logo.svg)

 

## 4. Tailwind CSS

 

- **Uso principal:** Diseñar interfaces de usuario web de forma rápida y personalizada mediante la combinación directa de clases de utilidad de propósito único en el código HTML.

- **Empresa o vacante real:** Vercel y numerosas startups.

- **Enlace de referencia:** [Tailwind CSS Oficial](https://tailwindcss.com/)

![Tailwind](https://upload.wikimedia.org/wikipedia/commons/d/d5/Tailwind_CSS_Logo.svg)

 

## 5. TypeScript

 

- **Uso principal:** Añadir tipado estático y herramientas avanzadas a JavaScript para desarrollar aplicaciones web grandes y complejas de forma más segura.

- **Empresa o vacante real:** Microsoft.

- **Enlace de referencia:** [TypeScript Oficial](https://www.typescriptlang.org/)

![Typescript](https://upload.wikimedia.org/wikipedia/commons/f/f5/Typescript.svg)
